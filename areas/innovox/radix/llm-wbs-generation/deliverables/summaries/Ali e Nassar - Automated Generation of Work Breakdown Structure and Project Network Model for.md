- **Citation key**: alinodateautomated
- **Objective**: Propose an engineering software application that helps civil engineers plan, design and manage transportation engineering projects, optimising earthwork volume allocation and then deriving part of the Work Breakdown Structure — specifically the Activity List network model — used to compute project cost and time.
- **Method**: The software optimises earthwork volume allocation by identifying the most economical combinations of cut and fill cells, minimising excavation and compaction costs. From the optimisation results it establishes an Activity List network model. Initially prototyped in Microsoft Excel and reimplemented in MATLAB when Excel proved insufficient.
- **Key findings**:
  - Automated calculation of the most economical cut/fill cell combinations replaces slow, error-prone manual computation.
  - The optimisation output feeds directly into an Activity List network model, letting managers determine soil-partition volumes.
  - Each soil partition is treated as a separate contract, since price and equipment differ between partitions.
- **Relevance to theme**: A **pre-LLM baseline**. The WBS is generated by deterministic optimisation, not by a language model, which makes it useful precisely as the prior art against which LLM-based generation should be compared. The structure produced is narrow — an activity list for earthworks — rather than a full project WBS, and no evaluation of structural completeness or coverage is reported.
