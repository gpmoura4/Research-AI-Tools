# Ajustes T02 — Nomear por extenso itens citados só pelo ID ou pelo número

- **Manuscrito**: smip-famo-framework · **Versão de referência**: `paper/v1-2026-10-08.pdf` (texto conferido na cópia de revisão, após a T01)
